# Restful Booker — API Testing

This project contains API testing documentation and Postman requests for the Restful Booker API.

## Base URL

```text
https://restful-booker.herokuapp.com
```

## Tested Endpoints

- `GET /booking`
- `GET /booking/{id}`
- `POST /booking`
- `POST /auth`
- `PATCH /booking/{id}`
- `DELETE /booking/{id}`

## Validation Areas

- HTTP status codes
- Response body
- JSON schema and data types
- Required fields
- Authentication
